# COMP 484 — HW8 Personal Resume Part 3

Personal resume website for Angelo, a Computer Science student at California State University, Northridge.

## Features
- Fixed navigation menu without a list; each item links to a resume section.
- Downloadable PDF resume in `files/angelo-resume.pdf`.
- Font Awesome icons in the footer and skills section (version 7.3.1).
- Education section background image with an RGBA linear-gradient overlay, using the background-image technique shown in COMP 484 Week 7.
- External stylesheet at `css/styles.css`.
